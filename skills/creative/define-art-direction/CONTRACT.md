# Art contract fields

This is a field guide, not a mandatory form. Write only rules that change production or review decisions.

| Field | Useful content |
| --- | --- |
| Authority | Candidate or selected; user decision or source; superseded direction if any. |
| Intent | Audience, setting, emotional effect, and intended use. |
| References | Creator/work/source; trait to borrow; trait to exclude. |
| Shape | Silhouette, proportions, shape families, identity landmarks, simplification. |
| Surface | Contour, brush or line behavior, texture scale, material response, shading, light. |
| Color | Palette roles, contrast, value hierarchy, accents, semantic colors where relevant. |
| Composition | Framing, camera, focal hierarchy, negative space, density, cropping. |
| Graphics | Type roles, lettering, mark construction, icons, borders, layout relationships. |
| Motion | Weight, timing, exaggeration, deformation, camera; link detailed motion rules if needed. |
| Constants and variation | What preserves identity; what may change by subject, state, or scene. |
| Production | Target scale, dimensions, transparency, layers, orientation, formats, code or raster constraints. |
| Avoid | Concrete failure modes; rejected examples only when they clarify a likely mistake. |
| Proof | Representative sample and observable checks in the requested medium at intended size. |

For a series, an identity block can name recurring features, palettes, camera, light, and contour. Prompts and code read it instead of inventing each item separately.

The project contract owns specific colors, mascots, and techniques. Do not make one project's choices universal skill rules.
