# Prompt pack

Use this shape when a series needs shared identity. Adapt length to the tool and task.

## Shared identity block

Describe recurring proportions, contours, materials, palette roles, lighting, camera, and landmarks. Point to the selected contract and actual reference files. Specify what the generator receives, not just what exists on disk.

## Per-asset request

- **Purpose and subject:** what the image depicts and where it is used.
- **Variable:** pose, expression, scene, item, or action that changes.
- **Composition:** view, framing, placement, crop, scale, and empty space.
- **Output:** dimensions or aspect ratio, background/transparency, layers or cutouts.
- **Avoid:** specific distortions or conflicting interpretations.

Combine the blocks into a paste-ready prompt. Keep asset ID, prompt, references, output path, and review state together when a saved pack is useful.

## Edit brief

Name the image to edit. State the requested change, identity/style/composition features to preserve, and changes to transparency or dimensions. Avoid regenerating untouched assets as a side effect.

## Iteration note

Record the visible problem and the instruction changed to address it. A selected output can become an anchor after user selection; failed outputs remain studies.
